# ЕНТ физика пробник 1

Пробный тест ЕНТ по физике: 40 заданий, баллы по правилам ЕНТ (максимум 50) и разбор ошибок после завершения.
Работает как PWA: можно установить на телефон и проходить без интернета.

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `ent-fizika`), публичный.
2. Нажми **Add file → Upload files** и перетащи всё содержимое этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md` и папку `icons`. Нажми **Commit changes**.
3. Открой **Settings → Pages**. В разделе **Build and deployment** выбери **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажми **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://<твой-логин>.github.io/ent-fizika/`.

## Как установить на телефон

- **Android (Chrome):** открой сайт → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iPhone (Safari):** открой сайт → «Поделиться» → «На экран „Домой“».

После первого открытия тест работает и без интернета.

## Если поменяла вопросы

Измени номер версии в первой строке `sw.js` (например, `ent-fizika-v2`), иначе у тех, кто уже открывал сайт, может остаться старая версия.
